# Reporting security issues

Report vulnerabilities privately through GitHub's [private advisory form](https://github.com/KamilTahiri/SkillHub/security/advisories/new). If the form is unavailable, open an issue asking for a private contact and leave out reproduction details, credentials, and local skill contents.

Include the SkillHub version, the affected operation, and the smallest reproduction you can share. For deployment or filesystem issues, use a disposable profile and remove identifying paths from logs.
